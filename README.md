## Описание

Выполнение лабораторной работы № 3 «Объектно-ориентированное программирование на Python».

Цель — изучить классы, объекты, инкапсуляцию, наследование, полиморфизм и паттерны проектирования.

Вариант 1: средняя сложность — задания **1, 3, 5**; повышенная сложность — задания **1, 4**.

Каждое задание находится в отдельном модуле с функцией `main()` и защитой `if __name__ == "__main__"`. При импорте модуля демонстрация не запускается.

## Требования и проверка стиля

- Python 3.9 или выше.
- Для запуска программ достаточно стандартной библиотеки Python.
- Для проверки оформления кода используется flake8.

Установите flake8:

```bash
python -m pip install flake8==7.3.0
```

Проверьте оформление кода:

```bash
python -m flake8 .
```

Для включения проверки перед коммитами настройте Git-хук из папки проекта:

```bash
git config core.hooksPath hooks
chmod +x hooks/pre-commit
```

На Windows эти команды выполняются в Git Bash. Хук `pre-commit` проверяет все Python-файлы рабочей папки, а не только изменения, добавленные в индекс Git. При обнаружении ошибок flake8 коммит отменяется.

## Выполненные задания

### Средн.1 — задание 1: класс «Книга»

Файл `book.py`. Класс `Book` хранит поля `title` и `author`, которые задаются при создании объекта через `__init__()`.

Метод `__str__()` возвращает текстовое описание книги. В `main()` создаётся объект, выводятся его название, автор и текстовое представление.

Запуск:

```bash
python book.py
```

### Средн.2 — задание 3: класс «Банковский счёт»

Файл `bank_account.py`. Класс `BankAccount` хранит баланс в защищённом атрибуте `_balance`. Свойство `balance` позволяет прочитать баланс без прямого присвоения через это свойство.

Метод `deposit()` пополняет счёт, а `withdraw()` снимает деньги. Оба метода возвращают новый баланс. Для точных денежных вычислений используется `Decimal` из стандартной библиотеки Python.

Начальный баланс не может быть отрицательным, а сумма операции должна быть больше нуля. Некорректные суммы и суммы с долями меньше копейки отклоняются. При попытке снять больше доступного баланса возникает `ValueError`, состояние счёта не меняется.

В `main()` показаны пополнение, снятие и обработка ошибки при недостатке средств.

Запуск:

```bash
python bank_account.py
```

### Средн.3 — задание 5: наследование «Животное» → «Собака»

Файл `animal.py`. Класс `Animal` хранит имя животного и определяет метод `speak()`, возвращающий общее описание звука.

Класс `Dog` наследуется от `Animal`, использует его конструктор и переопределяет `speak()`, возвращая описание лая собаки.

В `main()` объекты обоих классов помещаются в список. В цикле у каждого вызывается один и тот же метод `speak()`, но результат зависит от класса объекта. Это демонстрирует наследование и полиморфизм.

Запуск:

```bash
python animal.py
```

### Повыш.1 — задание 1: паттерн Singleton

Файл `singleton.py`. Класс `AppSettings` реализует паттерн Singleton для хранения настроек программы.

Метод `__new__()` создаёт объект при первом вызове и сохраняет его в атрибуте класса `_instance`. При следующих вызовах возвращается тот же экземпляр. Словарь настроек создаётся только один раз, поэтому повторный вызов класса не сбрасывает данные.

Метод `set_setting()` сохраняет настройку, а `get_setting()` возвращает её значение или значение по умолчанию.

В `main()` идентичность двух ссылок проверяется через `is`. Также демонстрируется, что изменение настроек через одну ссылку видно через другую.

Учебная реализация рассчитана на однопоточную работу в одном процессе.

Запуск:

```bash
python singleton.py
```

### Повыш.2 — задание 4: паттерн Strategy для расчёта цены

Файл `strategy.py`. Абстрактный класс `PricingStrategy` задаёт общий интерфейс `calculate(price)` с помощью `ABC` и `abstractmethod`.

Стратегия `RegularPrice` возвращает цену без изменений. Стратегия `PercentDiscount` хранит процент скидки и рассчитывает итоговую цену по формуле:

```text
итоговая цена = исходная цена × (1 − процент скидки / 100)
```

Один класс `PercentDiscount` поддерживает разные проценты, поэтому логика скидок не дублируется в отдельных классах.

Контекст `PriceCalculator` проверяет исходную цену и передаёт расчёт выбранной стратегии. Метод `set_strategy()` позволяет заменить алгоритм без создания нового калькулятора. Отрицательные и неконечные цены, а также проценты вне диапазона от 0 до 100 отклоняются.

В `main()` показаны цена без скидки и смена стратегий для скидок 10%, 20% и 50%. Вычисления выполняются с `float`; до двух знаков округляется только вывод результата.

Запуск:

```bash
python strategy.py
```
